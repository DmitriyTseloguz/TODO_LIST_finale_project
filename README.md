# TODO-List Веб-сервер

Веб-сервер для управления задачами с поддержкой повторяющихся событий. Реализован на Go с использованием SQLite для хранения данных.

## Особенности

- Создание, чтение, обновление и удаление задач
- Поддержка повторяющихся задач по правилам (ежедневно, ежегодно)
- Автоматический расчёт следующей даты для повторяющихся задач
- Готовый фронтенд для взаимодействия через браузер

## Выполненные задания со звёздочкой

- Поддержка настройки порта через переменную окружения `TODO_PORT`
- Возможность указания пути к файлу БД через `TODO_DBFILE`

## Запуск проекта

### Предварительные требования

- Установленный Go 1.16+
- SQLite3

### Установка и запуск

1. **Клонировать репозиторий:**

git clone https://github.com/yourusername/todo-list.git

cd todo-list

2. **Установить зависимости:**

go mod download

Создать файл .env:

3. **Создать файл .env:**

TODO_PORT=7540

TODO_DBFILE=scheduler.db

5. **Запустить сервер:**

go run main.go

Сервер будет доступен по адресу: http://localhost:7540

### Запуск тестов

1. **Убедитесь, что сервер запущен**

2. **Выполните команду:**

go test ./tests

Параметры тестов (при необходимости изменить в tests/settings.go):

- Port: Порт для тестового сервера

- DBFile: Путь к тестовой базе данных

- FullNextDate: Тестировать расширенные правила повторений (false по умолчанию)

### API Endpoints

- GET /api/tasks - Список всех задач

- POST /api/task - Создать задачу

- GET /api/task?id={id} - Получить задачу по ID

- PUT /api/task - Обновить задачу

- DELETE /api/task?id={id} - Удалить задачу

- POST /api/task/done?id={id} - Отметить задачу выполненной

- GET /api/nextdate - Рассчитать следующую дату выполнения

### Примеры запросов

Создание задачи:

- curl -X POST -H "Content-Type: application/json" -d '{
  "date": "20240101",
  "title": "Пример задачи",
  "comment": "Тестовый комментарий",
  "repeat": "d 7"
}' http://localhost:7540/api/task

Получение списка задач:

- curl http://localhost:7540/api/tasks
